# 002 - Service Enumeration

## Difficulty

Level 1

## Goal

Learn how to identify open TCP services on an owned Linux target and collect basic service details with Nmap from Kali.

## Lab summary

In this lab, you will use Kali to enumerate services on a sandboxed Linux target at `192.168.50.10`. You will start with a basic port scan, add service and version detection, run safe default scripts, save the results, and compare your findings against expected output examples.

Only run these commands against systems you own or have explicit permission to test. Do not run this lab against live third-party systems.
