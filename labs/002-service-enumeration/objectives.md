# Objectives

By the end of this lab, you should be able to:

- Confirm the target IP before scanning.
- Run basic TCP port discovery with Nmap.
- Identify common Linux services by port, protocol, product, and version.
- Use safe Nmap default scripts for light service enumeration.
- Save scan output in reproducible text files.
- Summarize enumeration results without modifying the target.

## Success criteria

- You can explain the difference between port discovery and service/version detection.
- You can identify at least three open services on `192.168.50.10`.
- You have saved Nmap output under `results/logs/`.
- You have completed `results.md` and `lessons-learned.md`.
