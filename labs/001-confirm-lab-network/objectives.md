# Objectives

By the end of this lab, you should be able to:

- Identify the expected lab IP addresses for the Mac, Kali VM, and Raspberry Pi.
- Confirm the Kali VM's local IP address with `ip addr`.
- Confirm whether the Kali VM can reach the Mac and Raspberry Pi with `ping`.
- Confirm whether the Mac and Raspberry Pi can reach the Kali VM with `ping`.
- Use `arp` to check whether successful local communication created neighbor table entries.
- Record pass, fail, and follow-up notes before starting later labs.

## Success criteria

- The Kali VM is using `192.168.50.10`.
- The Mac host is reachable at `192.168.50.20`.
- The Raspberry Pi is reachable at `192.168.60.10`, or the routing gap is documented clearly.
- `results.md` contains actual command results and next actions.
