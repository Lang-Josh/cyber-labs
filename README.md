# Cyber Labs

This repo stores reproducible cybersecurity labs for attack practice, SOC practice, detection engineering, and sandboxed network training.

## Repo purpose

Each lab should include:
- Goal
- Difficulty
- Hardware required
- Network topology
- Setup steps
- Commands to run
- Expected outputs
- Results
- Cleanup steps
- What was learned

## Main folders

- labs/ - Finished or in-progress labs
- templates/ - Reusable lab templates
- shared/ - Common IP plans, hardware inventory, commands, and troubleshooting
- scripts/ - Deploy, reset, and evidence collection scripts
- detections/ - Wazuh, Sigma, Sysmon, and detection content
- diagrams/ - Network and lab diagrams
- agent-handoff/ - Notes used by Codex and Claude Code to coordinate work
